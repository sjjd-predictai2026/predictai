نموذج لدعم قرار الصيانة V7.3 - حزمة PWA

الملفات: index.html، manifest.webmanifest، service-worker.js، icon-192.png، icon-512.png.

التحديث على GitHub Pages:
1. فك ضغط الحزمة.
2. ارفع الملفات إلى جذر مستودع المشروع واستبدل الملفات ذات الأسماء نفسها.
3. اضغط Commit changes وانتظر تحديث GitHub Pages.
4. افتح الموقع من Chrome أو Edge وثبّته عبر Install app / تثبيت التطبيق.
5. للعمل دون إنترنت، افتح التطبيق مرة واحدة باتصال الإنترنت حتى تُحفظ الملفات.

مهم: لا تحذف ملفات أخرى من المستودع. بيانات البرنامج المحلية قد تكون محفوظة على الجهاز الحالي، فلا تمسح بيانات الموقع أو ذاكرة التطبيق قبل أخذ نسخة احتياطية. دعم العمل دون متصفح غير مضمون في إصدارات Windows القديمة.
